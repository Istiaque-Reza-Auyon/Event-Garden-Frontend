This is a project using TypeScript, React.js, Next.js, Express.js, PostgreSQL, and Sequelize. The project aims to build an event management platform for event organizers with easy management of their events, from promotion to ticket sales and event attendees, with options to explore events and buy tickets on one platform. 

## Getting started

```bash
cd event-garden
npm install
cp .env.example .env      # then set DATABASE_URL, Cloudinary settings, NEXT_PUBLIC_URL = <external backend URL> and AUTH_SECRET
npm run dev               # http://localhost:3000
```
